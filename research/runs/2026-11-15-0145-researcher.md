## What each result teaches

1. **Round-number limit fades lose before costs, consistently** (R006: negative in every year, session and side, t -3.5).
   The hypothesised 57% win rate came in at 45%. This is the third time (R001a, R002a, R006) that a resting limit placed
   *ahead of* price for a fade is adversely selected: a limit fills exactly when flow is pushing through it. The 00/50
   level adds nothing that protects against that. Limit entries are a cost saving only when the fill carries no
   information (time-triggered entries), not for level fades.
2. **No stop-cascade continuation either** (R007: ~0 in every year). Taken with R006, round-number order clustering is
   not visible as a tradable effect at M5/1h in HistData 2018-21. Note R006's loss is not explained by R007's
   continuation (R007's edge is ~0), so it is mostly the generic limit-fill selection, not a round-number effect.
   A control (same limit fade at arbitrary, non-round levels) would confirm that, but it cannot produce a strategy, so
   I did not spend an eval on it.
3. **No pre-fix USD drift in EURUSD 2018-21** (R008: +0.10, t 0.1; positive in 2018/19, negative in 2020/21). Either
   the effect is concentrated in other USD pairs or in a shorter window right before the fix, or it has faded since
   the paper's sample. Not iterating: narrowing the window after seeing this would be fitting.
4. **The gate arithmetic** (useful for choosing future ideas): with ~1000 trades the gate needs edge/std >= 0.095 and
   edge >= 1.35 pips (cost ~1.05 + 0.3). A multi-hour hold has std ~20-35 pips, so it needs ~2-3.5 pips of edge per
   trade; a 10/10-pip bracket needs ~57% wins. Every effect measured so far in EURUSD sits at <= 1.5 pips with t < 2.
